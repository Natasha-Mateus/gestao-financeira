# Gestão Financeira (Casal)

App pessoal de gestão financeira para o casal, com suporte a leitura de cupom fiscal via IA Gemini (Vercel Serverless Function).

## Atualizações Recentes (v1.1)
- **Navegação Por Mês (Calendário):** Presente em todas as telas para visualização e consulta de histórico fácil.
- **Formulários Colapsáveis:** Botões para esconder/mostrar as fichas de cadastro para economizar espaço e melhorar visualização no celular.
- **Responsividade Mobile Aprimorada:** Tabelas com rolagem horizontal e ajustes de layout para smartphone.
- **Edição em Todas as Abas:** Edição diretamente nos cards/listas (exceto Dashboard, que permanece para consulta analítica).
- **Módulo 'Variáveis':** Integração com Cartão de Crédito e envio automático dos gastos selecionados para o extrato de cartões.
- **Submódulos do Cartão no Menu:** Meus Cartões, Vale Alimentação, Lançamentos e Faturas Futuras no menu lateral.
- **Múltiplas Caixas de Reserva:** Múltiplas caixas por pessoa com soma individual do Daniel, da Natasha e Total Consolidado.
- **Identificadores Padrão:** 'Apelido - Titular' para cartões e 'Pessoa - Tipo - Nome' para contas bancárias.
- **Filtro no Cartão:** Inclusão da categoria 'Delivery' e filtro por categoria.

## Implantação / GitHub
Basta dar push nesta pasta inteira para o seu repositório no GitHub. O Vercel detectará e atualizará a aplicação automaticamente.
